# Varun skills

Practical agent skills for architecting solutions, building grounded POCs, and telling the technical story.

**Implemented skills: 0.**

This is an installable packaging foundation, not a working collection of skills yet. It adds no skill commands, MCP servers, hooks, or canvases. The planned families have not been implemented.

Install from the `varun` marketplace:

```shell
copilot plugin marketplace add VeVarunSharma/skills
copilot plugin install varun-skills@varun
```

See the [main README](https://github.com/VeVarunSharma/skills#installation) for Copilot app and VS Code steps, updates, and platform limitations, and [CONTRIBUTING](https://github.com/VeVarunSharma/skills/blob/main/CONTRIBUTING.md) for authoring and validation.
